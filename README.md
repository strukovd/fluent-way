# Таблицы
- topics - темы\статьи (Present Simple, Часы\Время, и т.д.) (id, name)
- user_topic - привязка топика к пользователю, +прогресс по теме, будет хранить некий ключ (или тег) к которому будут добавляться характерные тренажеры нацеленные на практику конкретной темы (например: Present Simple, ..) (user_id, topic_id, started_at, status (in_progress, done), score (1–100))
- sentences (преложения) - набор преложений для практики (id, sentence (предложение), tense? (Present Simple), level (уровень сложности), tags?, озвучка, лайки)
- word_sentences?? (токены (слов) предложения) - если есть предложение "I want to improve my English" его можно разбить на токены слов (want, improve, ..), при попадании и успешной практике предложения, прибавлять балл к используемым словам (токенам) в словаре как опыт в user_word (+1 например), что бы пометить что пользователь видел слово, а значит практиковал его (даже если явно не добавлял слово) (или делать это на фронте или в моменте завершения).
- topic_sentences - (связка тема_предложение) - при генерации предложения, выяснять к каким темам оно относится, например present simple, а значит хранить в таблице связку, что бы те кто изучает Present Simple в выборку получали это предложение.
- #situation#_sentences - привязка предложения к дургим темам\интересам\ситуациям (тегам) - типа IT, дом, работа, что бы так же это можно было потом регулировать по категориям.
- daily_tasks (id, user_id, date, task_type (write_sentence, listen, use_words), payload (json), is_done)
